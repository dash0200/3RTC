# M2 checklist: run on a Windows 10 or 11 PC

From `desktop\`: `.\dev.cmd -Prod` (or `-Web`). Have a friend (or your phone) on 3rtc.me in the
same room for the voice lines. Tick each line; anything that fails, note what you saw.

## Push-to-talk (More → Voice settings → Push-to-Talk)
- [ ] Picking Push-to-Talk turns the mic off; the dock says "Hold ~ to talk"
- [ ] Hold `~` with 3RTC in front: the dock says "Talking", a short chirp, your friend hears you
- [ ] Let go: another chirp, about 0.2 s later your friend hears nothing
- [ ] Same with another app in front (Notepad, a browser, a game in a window): the key still works,
      and it still types `~` in that app (nothing is blocked)
- [ ] Record a new key: click the key box, press a key or a combination (Ctrl + Shift + T) or a
      mouse side button, let go; it shows the new key, and it works
- [ ] Typing `~` in 3RTC's own chat box doesn't open the mic
- [ ] Holding the mic button with the mouse talks too
- [ ] With an app running as administrator in front (e.g. Task Manager), a warning says
      push-to-talk can't see keys there
- [ ] Release Delay chips change the delay; the chirp switch and "Preview Sound" work
- [ ] Back to Open Mic: M and the mic button mute again

## Global hotkeys (Voice settings → Global Hotkeys)
- [ ] Set Mute / unmute to a combination (e.g. Ctrl + Shift + M): it mutes and unmutes with
      another app in front
- [ ] Set Deafen / undeafen: it works the same; × clears a hotkey

## Tray
- [ ] The 3RTC icon is in the tray (by the clock); hovering says the room, people and mic state
- [ ] Right-click: Open 3RTC, Mute microphone (ticked when muted), Deafen, Leave room, Quit 3RTC
      all work
- [ ] Closing the window keeps the call going; a notification says it's still running (first time
      only); clicking the tray icon brings the window back
- [ ] The window and taskbar show the red 3RTC icon

## Notifications (More → Desktop)
- [ ] With 3RTC hidden or behind another app, someone joining shows a Windows notification
- [ ] A chat message with `@YourName` shows "… mentioned you"
- [ ] Nothing shows while 3RTC is in front, or with Do not disturb on

## Start with Windows (More → Desktop)
- [ ] Off at first; turning it on and signing out and in starts 3RTC hidden in the tray
- [ ] Turning it off stops that

## Links and one app
- [ ] Starting 3rtc.exe again while it runs just brings the window to the front
- [ ] Win + R → `3rtc://join/12345` (a real room code): 3RTC asks "Join room 12345?";
      Join joins, Not now does nothing; from inside another room it says you'll leave it first
- [ ] The Invite tab shows `3rtc://join/<code>` for friends with the app; clicking copies it

## Rejoin
- [ ] Leave a room: the home screen shows "You were in room …  Rejoin"; Rejoin gets you back in
- [ ] As host, Rejoin gets the room back with the same code; × hides the card
- [ ] The card is gone after 30 minutes
