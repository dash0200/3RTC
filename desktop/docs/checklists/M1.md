# M1 checklist: run on a Windows 10 or 11 PC

Get the code (`git checkout CLAUDE && git pull`), then from `desktop\`: `.\dev.cmd -Web`
(local server + the app + the web app in your browser). Or use `3rtc.exe` from the `desktop`
GitHub workflow's `3rtc-windows-x64` artifact against the real server.

Tick each line; anything that fails, note what you saw.

## Looks
- [ ] Home: same as 3rtc.me (header, headline, name box, Create a room, 5 code boxes, room preview, footer with Server settings)
- [ ] Room: header (room code chip, Waiting for friends / Connected pill, Invite friends, Hide Panel), stage, dock, side panel
- [ ] Fonts look like the website (Figtree text, Bricolage Grotesque headings, JetBrains Mono room codes)
- [ ] Window can be resized down to 1024×640 without anything cut off

## Rooms and chat
- [ ] Create a room; copy the code (click the chip) and the invite link (Invite tab)
- [ ] A friend on 3rtc.me joins with the code or the link: their name shows in the dock, People and chat
- [ ] Chat both ways; HOST badge on the host's messages; unread count on the Chat tab / Panel button
- [ ] Join a room made on 3rtc.me by typing its code; a wrong code says "Room … not found"
- [ ] Make the friend host from People; the 👑 message appears on both sides
- [ ] Leave: "Leave room …?" dialog, Stay / Leave room; back on the home screen

## Voice (the main thing)
- [ ] Mic starts off; click Mic: the friend hears you, clearly, with no echo from your speakers
- [ ] The friend talks: you hear them; a green ring on their avatar while they talk, on yours while you talk
- [ ] Mute / unmute with the Mic button and with M (not while typing in chat)
- [ ] Deafen (headphones button): you hear nobody and your mic goes off; Mic on undeafens
- [ ] Pick a different microphone and speaker (caret next to Mic, or More → Voice settings); it switches live
- [ ] Minimise the window for 5 minutes while talking: voice keeps going both ways
- [ ] 30 minutes in a call with two web users: no drops (write down CPU and memory from Task Manager)

### No voice? Read the console
The console window behind the app says what the sound card is doing (lines start with `audio:`):
- `audio: sound card open (N microphones, M speakers ...)` then one line per device. If it says
  `the sound card could not be opened` instead, the app sends silence and plays nothing (the app
  also shows a 🔇 toast).
- `[REC : 10000msec ...] callbacks: ..., level: ...` every 10 s while your mic is on: callbacks
  near 1000 and a level above 0 mean the microphone is delivering sound.
- `[PLAY: 10000msec ...]` every 10 s while you're in a call: the speakers are being fed.
- `audio with <peer>: sent ... packets (mic captured ... s, level ...); received ... packets
  (... samples played ...)` every 10 s per person: whether voice actually crosses the network.
